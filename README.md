# AIDetector

I have noticed the rapid increase in AI generated imagery (and I am 1000000% sure you have noticed as well). I am kind of shocked with seeing so many people not able to tell when something is AI or not, so I build this app to help that! It's designed to be as painless to install and use as possible. I also didn't make this application for any form of monetary gain, I don't request donations, put weird licensing on my work, obfuscate code (any more than my messy coding already does), or anything like that. Feel free to use this project for literally whatever!


Just ```pip install -r requirements.txt``` then ```python main.py```
